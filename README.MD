# Автоматический обработчик заказов клееного бруса (ИИ-Конвейер)

Проект разработан в качестве выполнения тестового задания на позицию стажёра по применению ИИ в разработке ПО в компанию **«Скиллтон»**.

##  О проекте и архитектурном выборе

Цель системы — автоматический разбор разнородных входящих запросов на изготовление клееного бруса (чертежи от руки, скриншоты переписок, текстовые письма), извлечение параметров спецификации и формирование стандартного списка-заказа.

### Почему Native Stack (Java + TypeScript) вместо Visual No-Code (n8n)?
В ТЗ была предложена концепция автоматизации на базе n8n. Однако в рамках данного решения архитектура была реализована на полноценном бэкенде **Java (Spring Boot 3)** и фронтенде **TypeScript**, что даёт проекту ряд критических преимуществ:
1. **Надёжная обработка бинарных данных:** Визуальные кубики n8n часто дают сбой при работе с сырыми потоками данных (multipart/form-data) при загрузке изображений. Native-код на Java гарантирует стабильную конвертацию картинок в `Base64` для передачи локальному ИИ.
2. **Строгая типизация (Type Safety):** Наличие интерфейсов на TypeScript и DTO-классов на Java полностью исключает runtime-ошибки при парсинге сложного JSON от нейросети.
3. **Расширяемость интерфейсов:** Бизнес-логика полностью отделена от каналов ввода. Текущая система параллельно поддерживает как **Email-интерфейс (IMAP/SMTP)**, так и **Web REST API** для подключения фронтенда, а в будущем может быть расширена до Telegram-бота без изменения ядра.

## 🛠 Архитектурные модули бэкенда (Java)

Код спроектирован по принципам чистой архитектуры и разделен на изолированные пакеты внутри `com.skillton.aihandler`:

*   `config/`: Конфигурация приложения, CORS-политики и слой безопасности **API-Key Auth Filter** для защиты эндпоинтов от несанкционированных внешних запросов.
*   `model/` (или `dto/`): Строго типизированные структуры данных (`OrderLineDto`, `AiResponseDto`), полностью повторяющие форму выходной таблицы из ТЗ.
*   `service/ai/`: Модуль интеграции с локальным **LM Studio** через OpenAI-совместимый HTTP-клиент. Содержит системный промт и отвечает за strict-JSON режим ИИ.
*   `service/mail/`: Планировщик (`@Scheduled`), который в фоне слушает почту по протоколу **IMAP**, скачивает новые заявки и автоматически отправляет обратно клиенту ответную HTML-таблицу по **SMTP**.
*   `controller/`: REST API контроллеры для интеграции бэкенда с клиентским приложением на TypeScript.

## 🧠 Локальная ИИ-модель и Промптинг

В качестве локального ИИ-движка выбрана open-source мультимодальная модель **Qwen2.5-VL-3B-Instruct-GGUF** (Vision-Language), запущенная локально через **LM Studio** на порту `1234`. Она превосходно распознает русский рукописный текст на чертежах и извлекает таблицы.

### Логика обработки и Промт:
Модель обучена возвращать строго валидный JSON. Согласно требованиям ТЗ, в систему заложена следующая логика:
* Если параметры бруса ясны ➔ заполняются соответствующие поля.
* Если данные в запросе отсутствуют или неоднозначны (например, не указан материал) ➔ ИИ обязан самостоятельно сделать **Предположение (Пункт 1 в ответе)** и сформировать **Список уточняющих вопросов к заказчику (Пункт 2 в ответе)**.

## 🚀 Инструкция по запуску

### 1. Подготовка локального ИИ
1. Запустите **LM Studio**.
2. Скачайте и запустите модель `Qwen2-VL-7B-Instruct` (или `Qwen2-VL-2B` для экономии ресурсов).
3. Перейдите во вкладку **Local Server** и нажмите **Start Server** (порт по умолчанию `1234`).

### 2. Настройка окружения
Создайте файл `.env` в корне проекта (рядом с `pom.xml`):

```env
# Ключ авторизации для TypeScript фронтенда
APP_API_KEY=skillton_super_secret_token_2026

# Параметры LM Studio
LM_STUDIO_URL=http://localhost:1234/v1
AI_MODEL_NAME=qwen2-vl-7b-instruct

# Настройки почтового шлюза (например, Яндекс)
IMAP_HOST=imap.yandex.ru
IMAP_PORT=993
IMAP_USER=ai@skillton.ru
IMAP_PASS=ваш_секретный_пароль_приложения

SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=ai@skillton.ru
SMTP_PASS=ваш_секретный_пароль_приложения
```

### 3. Запуск бэкенда
```bash
mvn clean package
mvn spring-boot:run
```
